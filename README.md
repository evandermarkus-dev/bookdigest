# BookDigest

**AI-powered book summaries from your own PDFs.** Upload a book, pick a summary style and language, and get a structured digest you can read, listen to, chat with, share, or export to Notion and Readwise.

🔗 **Live:** [bookdigest-pi.vercel.app](https://bookdigest-pi.vercel.app)

---

## What it does

BookDigest turns a PDF (up to 50 MB) into a structured summary generated by Claude. Before summarizing, a short questionnaire captures *why* you're reading the book, so the output is tailored to your goal rather than generic.

**Summary styles**

| Style | Focus |
|---|---|
| Executive | Core ideas and takeaways, fast |
| Study | Concepts and structure for learning |
| Action | Concrete steps you can apply |
| Research | Arguments, evidence and page references |
| Knowledge | Long-term reference notes |

**Features**

- **Nine output languages** — Swedish, English, German, French, Spanish, Norwegian, Danish, Finnish, or "same as the PDF" (auto-detected)
- **AI chat per summary** — ask follow-up questions grounded in the summary you generated
- **AI audio narration** — Claude writes a spoken script, OpenAI TTS narrates it, and the MP3 is cached in Supabase Storage
- **Claude Code skill builder** — turn a book's ideas into a ready-to-use Claude Code skill (persona + focus area)
- **Exports** — Notion pages and Readwise highlights, with page references preserved
- **Public share links** — revocable tokens at `/s/[token]`
- **Programmatic SEO** — ~200 static book pages in English (`/books/[slug]`) and Swedish (`/sv/books/[slug]`), plus sitemap and OG images
- **Account management** — onboarding, settings, GDPR account deletion

## Architecture

```
PDF upload ──► Supabase Storage ({user_id}/…)
                     │
                     ▼
        /api/summarize  ── auth + ownership check
                     │      ── Upstash rate limit + monthly tier quota
                     │      ── pdf-parse → text (capped at 80k chars)
                     │      ── Claude Sonnet → structured JSON summary
                     ▼
              summaries table ──► dashboard
                     │
     ┌──────────┬────┴─────┬───────────┬────────────┐
     ▼          ▼          ▼           ▼            ▼
 /api/chat  /api/audio  /api/skill  /api/export  /api/share
 (Haiku)    (Haiku+TTS) (Sonnet)    (Notion/RW)  (tokens)
```

```
app/          Routes, pages and API handlers
components/   UI (BookCard, PdfUpload, PricingClient, SkillBuilderModal …)
lib/          config.ts (all limits/tiers), prompts.ts, Supabase clients, ratelimit, email
lib/books/    Static data for the SEO book pages
outreach/     Python CLI that finds relevant Reddit/HN threads and drafts
              messages for manual review (nothing is posted automatically)
proxy.ts      Auth middleware (Next.js 16 naming — must export `proxy`)
```

All tunable constants (limits, styles per tier, file sizes, bucket name) live in `lib/config.ts`.

## Getting started

Requires Node.js ≥ 20.

```bash
git clone https://github.com/evandermarkus-dev/bookdigest.git
cd bookdigest
npm install
cp .env.example .env.local   # fill in your keys
npm run dev                  # http://localhost:3001 (note: port 3001)
```

### Environment variables

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase project |
| `SUPABASE_SERVICE_ROLE_KEY` | Server-only admin client (audio cache, webhooks) |
| `ANTHROPIC_API_KEY` | Claude |
| `OPENAI_API_KEY` | TTS narration |
| `STRIPE_SECRET_KEY`, `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`, `STRIPE_WEBHOOK_SECRET` | Billing |
| `STRIPE_READER_PRICE_ID`, `STRIPE_PRO_PRICE_ID` | Plan price IDs |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | Rate limiting (optional locally) |
| `RESEND_API_KEY`, `EMAIL_FROM` | Transactional email (optional locally) |
| `NEXT_PUBLIC_SITE_URL` | Base URL for email links |

For local Stripe webhooks:

```bash
stripe listen --forward-to localhost:3001/api/stripe/webhook
```
